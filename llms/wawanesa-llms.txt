# Wawanesa Insurance

> The Wawanesa Mutual Insurance Company (founded 1896, Wawanesa, Manitoba; headquartered in Winnipeg) is one of Canada's largest property and casualty mutual insurers, writing auto, home, condo, tenant, seasonal residence, farm and commercial lines across every province and territory through a 100% independent broker distribution model, alongside Wawanesa Life. Wawanesa runs policy, claims and billing on Guidewire InsuranceSuite. It operates a real broker-facing API programme standardized on CSIO — including a CSIO-aligned Commercial Small Business quote-and-bind API — but **none of it is public**: there is no developer portal, no API reference, no OpenAPI definition, no SDK, no sandbox and no self-serve signup. Integration is partner-gated through the broker channel.

**Generated by the API Evangelist enrichment pipeline on 2026-07-25. Method: generated from apis.yml, review.yml and the artifacts in this repository. Nothing below is synthesized — every claim links to a source.**

## Access posture

- **No public API.** `api.wawanesa.com` exists but returns HTTP 403 (nginx) at the root and for every path probed, including `/openapi.json`, `/swagger.json`, `/api-docs` and `/.well-known/*`. Only `/health` answers (plain-text `OK`).
- **No developer host.** `developer.wawanesa.com`, `developers.wawanesa.com` and `docs.wawanesa.com` do not resolve (no DNS).
- **No soft-404 traps.** `www.wawanesa.com` returns HTTP 200 with the site's catch-all HTML shell for any unknown path — including `/llms.txt`, `/.well-known/security.txt` and `/.well-known/api-catalog`. Those are not real documents.
- **Onboarding is human.** The only stated integration path is "contact your Wawanesa Business Development representative". There is no self-serve signup, no API key, and no documented machine-to-machine credential.
- **No GitHub organization**, no published SDK on npm / PyPI / RubyGems / NuGet / Packagist / crates.io, no public Postman workspace, no status page, no webhook or event catalog, no GraphQL, no gRPC, no MCP server.

## Standards and certifications

Canada's insurance connectivity standards body is **CSIO**, not ACORD — Wawanesa's own site search returns no results for "ACORD".

- [CSIO API Security Standards Certification](https://csio.com/news/wawanesa-insurance-achieves-api-security-standards-certification-safeguarding-data-and) (2024-10-29) — a standard authentication and authorization API model.

## Authentication

The only authentication metadata reachable anonymously is the identity layer in front of the gated Broker Platform. It governs broker sign-in, not any insurance API.

- [Okta broker issuer OIDC discovery](https://login.brokerplatform.wawanesa.com/.well-known/openid-configuration) — authorization_code / implicit / refresh_token / password / device_code, PKCE S256, DPoP algs advertised, 7 stock OIDC scopes.
- [Okta org authorization-server metadata (RFC 8414)](https://login.brokerplatform.wawanesa.com/.well-known/oauth-authorization-server) — 83 scopes, all Okta platform-management scopes.
- [Salesforce Experience Cloud OIDC discovery](https://brokerplatform.wawanesa.com/.well-known/openid-configuration) — 36 stock Salesforce platform scopes.

No insurance-business scope vocabulary (quote, bind, policy, billing, claims) is published anywhere.
